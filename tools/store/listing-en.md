## Description · required · up to 10,000 characters

```
Typer types any text into any Windows application as if a person were typing it: character by character, at a natural pace, with optional typos that it corrects itself. It works where plain pasting fails: chat apps, browser forms, virtual machine consoles, remote desktops and games.

How it works
Paste the text into Typer, click into the window it should go to and press F7. After a short countdown Typer activates that window and starts typing. F5 or Esc stops it at any moment. You can also pick a specific window from a list and Typer brings it to the front before it starts.

Human-like pace
Set the delay between characters and its randomness, plus extra pauses after words, punctuation and new lines. Turn on human typos: Typer hits a neighbouring key or swaps two letters, notices the slip at once or a few characters later and fixes it with Backspace. When speed matters, instant mode pastes whole lines through the clipboard.

Keys under control
A new line can be Enter, Shift+Enter, Ctrl+Enter or skipped, so a chat message is not sent halfway through. At the end Typer can press Enter or Tab to send the message or jump to the next field. Compatibility mode sends key codes instead of Unicode characters, which helps in games, VM consoles and remote desktop sessions.

Fragments and position
Split the text into lines or paragraphs. Typer remembers where it stopped, like a media player: F8 types the next fragment, F6 repeats the previous one, F7 types everything from the current position and F5 stops and rewinds. Handy for dictating lines, answering surveys or running commands step by step.

Data from a CSV file
Load a CSV file and placeholders such as {name} or {order} are filled from consecutive rows: one repetition per row or N repetitions with a pause. Built-in placeholders come on top: {n}, {total}, {date}, {time}, {datetime}, {clipboard}, {uuid}, {rand:1-100} and {rand:a|b|c}. The preview shows the finished text for every row before you start.

Macros
Record a keyboard and mouse sequence or build it from steps: text, key combination, pause, mouse move, click, drag, scroll and window activation. Edit the steps, set repetitions and give each macro its own global hotkey to run it from any application.

Presets
Save the text together with its settings and bring it back with one click. Full-window preview, import and export to JSON to move presets to another computer.

Look and privacy
Light and dark theme, English and Polish interface. Typer works entirely on your computer: no internet connection, no data collection, no account. Settings, presets and macros are plain JSON files on your disk.

Requirements: Windows 10 version 1809 or later, 64-bit, and the Microsoft Edge WebView2 Runtime (included in Windows 11).
```

## Product features · up to 20 items, 200 characters each, no bullets

```
Types text with a simulated keyboard into any window: chat apps, browser forms, VM consoles, remote desktop, games
Human-like pace: delay between characters with randomness, pauses after words, punctuation and new lines
Optional typos corrected like a person would: neighbouring key, swapped letters, fixed at once or a few characters later
Instant mode: whole lines pasted through the clipboard
New line as Enter, Shift+Enter, Ctrl+Enter or skipped; Enter or Tab at the end, e.g. to send a message
Compatibility mode with key codes for games, virtual machines and remote desktop
Split the text into lines or paragraphs with a media-player position: next, previous, start from the current place
Placeholders from a CSV file: one repetition per row or N repetitions with a pause, preview of the finished text
Built-in placeholders: {n}, {total}, {date}, {time}, {datetime}, {clipboard}, {uuid}, {rand:1-100}, {rand:a|b|c}
Macros: keyboard and mouse recording, step-by-step editing, repetitions and a global hotkey for every macro
Presets: text and settings in one place, full-window preview, JSON import and export
Global hotkeys on function keys: F7 start and pause, F5 stop, F6 and F8 fragments, F9 recording; all remappable
Target window from a list or automatically the last active window, with a countdown before the start
Light and dark theme, English and Polish
Works fully offline: no internet, no account, no data collection
```
